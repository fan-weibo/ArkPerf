# ArkPerf（方舟智诊） · 参赛作品简介

> **性能分析不该依赖个人经验，它应该是一套可复现的流程。**

ArkPerf 是一个能自己动手的性能分析 Agent：你说一句要分析什么，它在 OpenHarmony 设备上完成采数、判定、给建议，并把优化前后的对比沉淀成可复用的报告。

冷启动、内存、CPU、主线程卡顿这四类指标决定应用的第一印象，但目前测准、看懂、改好全靠手工——采样靠经验、因果靠猜、前后对比没有统一口径。这类工作要看结果改下一步，正适合交给 Agent：判断交给模型，采数的脏活交给测量服务。

**ArkPerf 的三个特点**：

- **测量外置**——采集逻辑是可插拔的 MCP 服务，加一类指标只需加一个服务，内核零改动；
- **知识按需加载**——诊断方法论写成技能文档，模型用到才读，可独立迭代；
- **审批可记忆**——"放行一次"沉淀为"这类以后不问"，粒度保守。

**效果**——在两个真实应用上完成验证：冷启动耗时降低 68.2%（p=0.0002）、CPU 占用降低 91.4%、内存峰值降低约 100 MB。

**技术栈**——Go（内核与 TUI）· Python（五个 MCP 测量服务）· MCP 协议 · OpenAI 兼容接口

纯终端界面，解压即用——执行 `arkperf tui`，输入一句话即可开始。
