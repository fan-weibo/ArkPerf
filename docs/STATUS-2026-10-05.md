## 3. 今晚（10-04）修复的 bug——都来自真实验收

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | **所有任务发不出去**（400） | grep 工具 schema 是原始字符串里手写 JSON，有个未转义引号 | 修掉；加全量 schema 校验测试 + provider 点名预检 |
| 2 | 设备列表页显示工具链报告 | 两个功能页共用一个异步结果槽，响应乱序覆盖 | 拆成 tcReport / dvReport |
| 3 | **中断后整个会话说不了话**（400） | 历史修整逻辑把工具回复删了、却留着带 tool_calls 的 assistant | 换成 sanitizeTail：补齐悬空 tool_calls 而不是删；6 个回归测试 |
| 4 | 回放丢工具调用 | transcriptLines 只回放 user/assistant | 完整回放，工具名从 tool_call_id 反查 |
| 5 | 「方舟智诊」标签重复/丢失 | 跨层传标志位，回放路径丢失 | 改为前端渲染时推导（每条 user 后第一段回答） |
| 6 | 新工作区跑完任务不出现 | 任务结束不刷新侧栏 | done 事件统一 refreshAll |
| 7 | 切会话后侧栏数据串台 | 见 #2 | 同 #2 |
